# Vemryx · `.github`

Organization profile and shared GitHub configuration for [**Vemryx**](https://github.com/vemryx).

## Structure

| Path | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | The README shown on the [Vemryx organization page](https://github.com/vemryx). GitHub reads it from `profile/` in this repository. |

## Editing the organization profile

1. Edit `profile/README.md`.
2. Push to `main`. The organization page updates within a few minutes.

Brand images and product icons are loaded from [vemryx.com](https://vemryx.com), so the profile always matches the website. The logo switches automatically between light and dark themes.

## Shared defaults

Files placed at the root of this repository (for example `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, or `ISSUE_TEMPLATE/`) become the default for every Vemryx repository that doesn't define its own.
